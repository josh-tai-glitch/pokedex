# 進化方式 整理

- 最常見：升到某個等級。例：小火龍 Lv16 → 火恐龍 Lv36 → 噴火龍。鯉魚王 Lv20 → 暴鯉龍。迷你龍 Lv30 → 哈克龍 Lv55 → 快龍。
- 進化石：皮卡丘 + 雷之石 → 雷丘。伊布 + 水/雷/火之石 → 水伊布/雷伊布/火伊布。
- 親密度：皮丘、小卡比獸 跟訓練家感情好就會進化。伊布親密度高時，白天升級 → 太陽伊布，晚上 → 月亮伊布。
- 通訊交換：鬼斯通交換給朋友就會變成耿鬼。
- 特定地點：伊布在青苔岩旁升級 → 葉伊布、冰岩旁 → 冰伊布（第 8 世代以後也可以用葉之石、冰之石）。
- 招式 + 親密度：伊布學會妖精屬性招式且感情好 → 仙子伊布。
- 幼年寶可夢（皮丘、小卡比獸）在第 2、4 世代才補上，是從蛋孵出來的。小卡比獸要讓卡比獸帶「滿腹薰香」生蛋才會孵出來。
- 有些寶可夢不會進化：超夢、夢幻、三聖鳥。
