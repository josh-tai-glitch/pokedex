## 概要
寶可夢在滿足特定條件後會改變外型與能力，稱為「進化」。大多數進化是單向且不可逆的。

## 進化條件一覽
| 方式 | 說明 | 圖鑑中的例子 |
|---|---|---|
| 等級 | 升到指定等級 | [[小火龍]] Lv16 → [[火恐龍]] Lv36 → [[噴火龍]]；[[鯉魚王]] Lv20 → [[暴鯉龍]] |
| 進化石 | 使用特定道具 | [[皮卡丘]] + 雷之石 → [[雷丘]] |
| 親密度 | 和訓練家感情好時升級 | [[皮丘]] → [[皮卡丘]]；[[小卡比獸]] → [[卡比獸]] |
| 親密度 + 時間 | 白天或晚上升級 | [[伊布]] → [[太陽伊布]]（白天）／[[月亮伊布]]（夜晚） |
| 通訊交換 | 交換給其他玩家 | [[鬼斯通]] → [[耿鬼]] |
| 特定地點 | 在特定岩石旁升級 | [[伊布]] → [[葉伊布]]、[[冰伊布]] |
| 招式 + 親密度 | 學會特定屬性招式 | [[伊布]] → [[仙子伊布]] |

## 分支進化
有些寶可夢依條件不同，會進化成不同的樣子，最有名的就是 [[伊布家族]]。

## 不會進化的寶可夢
[[超夢]]、[[夢幻]] 與 [[三聖鳥]] 都沒有進化前或進化後，詳見 [[傳說與幻之寶可夢]]。

## 暫時性的進化
戰鬥中才會發生、結束後會變回來的 [[超級進化]]，和一般的進化不同。
